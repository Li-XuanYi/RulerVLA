## 2. 新的训练和推理调用链

```text
训练：原 manifest → SpatialDataset → 同 episode actions[t:t+10]
    → MetricPipeline.prepare_train → MetricBatch
    → MetricTrainer → 原 pi05.compute_loss → full-FT AdamW → G2 checkpoint

推理：同步当前观测 → LiberoAdapter.from_metric_observation
    → 同一 MetricPipeline.prepare_inference → pi05.sample_actions
    → checkpoint 自带统计反归一化 → LIBERO [10,7]
```

两条链共用 MetricViewAdapter、几何生成、Metric Ruler、SixChannelInputs、Prompt Builder 和量化规范化统计。Echo 关闭。实时接口要求两路公制 depth、K/T、state8、episode、control_step 与 calibration_step；标定步不等于当前步会被拒绝。单元测试检查实时输入与存储样本约定相符；本轮未执行在线 simulator rollout。

Prompt 只由当前观测与公制配置构建；prepare_train 在构造观测前移除 actions，未来标签不能进入当前视觉或文本。超过 200 token 会拒绝，禁止静默截断。checkpoint 保存实际 SentencePiece 模型字节及哈希，恢复不依赖重新下载的 tokenizer 内容。

## 8. G3 所需接口与当前停止点

- `MetricBatch.observation/actions/identities` 已将模型当前输入、真实动作标签和样本身份分离。
- `MetricTrainer(objective=...)` 可在同一 NNX differentiated model 中替换组合 loss；原 `action_loss` 可直接复用。
- `model.embed_prefix` 提供共享视觉／语言表征入口；辅助头必须与主模型共同反向，不能用 detached 表征代替共享梯度证据。

**当前停止点是 G2 GPU 验收阻塞；本轮未进入 G3，也未启动 M0–M3 或30k训练。** H1/H2 的学习有效性、厘米读尺误差和跨尺度／跨视角泛化仍待后续受控实验。
